# Tutorials

These step-by-step lessons take you through the core features of Mimir, from your first campaign to your first game session.

## What You Will Learn

Each tutorial builds on the one before it:

1. **[Your First Campaign](./01-first-campaign.md)**: sign in, make a campaign, import the catalog
2. **[Your First Module](./02-first-module.md)**: add a module, a map and monsters
3. **[Running Your First Session](./03-first-session.md)**: place tokens, use fog of war and the initiative tracker
4. **[The Player Display](./04-player-display.md)**: show the map on a TV and give players their links
5. **[Creating Homebrew Content](./05-homebrew-content.md)**: make your own items, monsters and spells

## Prerequisites

- A running Mimir server, its address and the DM token. See [Run the Server](../how-to/run-server.md).
- A web browser. A desktop browser or a tablet both work.
- Some knowledge of D&D 5th Edition helps, but you do not need it.

## Time

Each tutorial takes 10 to 30 minutes.
