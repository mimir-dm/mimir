# LLM Tools (Removed)

The built-in LLM tools system was removed in v0.5.0. AI-assisted campaign management is now provided through the **MCP (Model Context Protocol) endpoint** of the server at `/mcp`, with the tools of the `mimir-mcp` crate.

See the [MCP Server reference](../../../reference/mcp-server.md) for the tools and the integration with Claude Code.
