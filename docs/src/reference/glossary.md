# Glossary

Terms used in Mimir.

## A

**Ambient Light**
: The lighting of a map where no light source shines: bright, dim or dark. You choose it when you upload the map.

## B

**Blackout**
: A state of the player display that hides the map and shows "Paused". Use it to set up a scene.

## C

**Campaign**
: A collection of modules, characters, documents and maps for one D&D game.

**Campaign Dashboard**
: The page of a campaign, with the tabs Campaign, Modules, NPCs, PCs and Homebrew.

**Copy from the Catalog**
: Making a homebrew item, monster or spell from a copy of a catalog entry.

## D

**Darkvision**
: A trait that lets a creature see in darkness up to a range, as if in dim light. Often 60 feet.

**DM Map**
: The page where the DM prepares a map and runs the session on it, with the initiative tracker beside it.

**DM Token**
: The secret of the server (`MIMIR_API_TOKEN`). The DM signs in with it. Claude uses it at `/mcp`.

**Document**
: A markdown text for notes, places or session prep. It belongs to a campaign or a module.

## F

**Fog of War**
: Hides the parts of the map that the player characters cannot see. It follows the PC tokens.

## G

**Grid**
: The squares of a map, each 5 feet. A UVTT file has its grid. For an image, you set the pixels of a square at upload.

## H

**Homebrew**
: Your own items, monsters and spells. They belong to one campaign and have the source HB.

## I

**Initiative Tracker**
: The panel beside the DM map that runs a combat: turn order, hit points, conditions and concentration.

## L

**Light Source**
: A torch or a lantern on the map. It changes what the party can see in dim or dark light.

**Line of Sight**
: What a creature can see from where it stands. Walls and closed doors block it on UVTT maps.

## M

**Mapgen**
: The procedural map generator. It makes Dungeondraft maps from YAML or biome presets.

**MCP (Model Context Protocol)**
: The protocol that lets Claude work with your campaigns. The server serves it at `/mcp`.

**Module**
: One adventure in a campaign. It has its own documents, NPCs, maps, monsters and player notes.

**Monster**
: A catalog or homebrew creature that a module uses in its encounters.

## N

**NPC (Non-Player Character)**
: A character that the DM plays.

## O

**Open Mode**
: A server with no DM token. Every caller is the DM. Use it only where no one else can reach the server.

## P

**PC (Player Character)**
: A character that a player plays. Made with the character wizard.

**Play Notes**
: The module document for notes during a session. Every module has one.

**Player Display**
: The page that shows the players the map as their characters see it, on a shared screen.

**Player Link**
: A link that gives one player access to their own character on their own device.

**Player Notes**
: Notes that a player writes on their character. The DM reads them on the sheet and on the module page.

**Player Page**
: What a player link opens: the display, the character sheet and the party.

**POI (Point of Interest)**
: A named marker on a map.

## S

**Shared Sheet**
: A character sheet that its player shares with the party, read-only.

**Source Book**
: An imported book of the catalog, for example PHB.

## T

**Token**
: A creature on the map: a PC, a monster or an NPC.

**Trap**
: A trap marker on a map, with its DC, trigger and effect for the DM.

## U

**UVTT**
: Universal Virtual Tabletop format. A map file with the image, the grid, the walls and the doors.

## V

**Vision**
: How far a token sees in bright light, in dim light and in darkness, and the light it carries.

**Viewport**
: The part of the map that a page shows. The DM map and each display have their own.
