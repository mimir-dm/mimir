# Reference Page

The reference page (`/reference`) is the D&D 5e catalog and the book reader. It shows what you imported. See [Manage Source Books](../../how-to/campaigns/manage-sources.md).

The page has two tabs: **Catalog** and **Books**. The tab is in the address (`?mode=catalog`, `?mode=reader`).

## Catalog

### Kinds

The side list groups the kinds of entries:

| Group | Kinds |
|-------|-------|
| Reference | Spells, Items, Bestiary, Conditions & diseases, Actions, Deities, Languages, Rewards, Psionics, Vehicles |
| Player | Classes, Races, Backgrounds, Feats, Other options & features |
| Rules | Tables, Variant rules |
| DM tools | Cults & boons, Objects, Traps, Hazards |

### Search and Filters

| Control | Function |
|---------|----------|
| **Name** | Search by name as you type |
| Filters | Depend on the kind, for example **Level** and **School** for spells, or **Type** and **Size** for monsters. **Any** turns a filter off. |
| **Results** | A table of the entries, with columns for the kind. Click a column heading to sort by it; click again to reverse. |
| **Load more** | Show the next results |

With more than 500 results, Mimir asks you to search by name or filter.

### Detail Drawer

Click an entry name to open its detail in a drawer: a stat block, a spell, an item and so on.

- A cross-reference in the text, for example a spell in a stat block, opens over the current entry.
- **← Back** returns to the entry before.
- **Close** closes the drawer.

The same drawer opens from the **Dangers** tab of a module page.

## Books

The reader shows the text of an imported book.

| Control | Function |
|---------|----------|
| **Book** | Choose the book |
| **Remove this book…** | Remove the book from the library, after a confirmation: its catalog entries and text go, as **×** in Settings |
| **Contents** | The chapters and headings. Click one to go to it. |
| **← Previous**, **Next →** | Go to the previous or next section |

The text shows its tables, insets, read-aloud boxes and images. A cross-reference shows a short summary when you point at it. Click it to open the detail drawer.

Only books that you imported with their text can be read. Without one, the reader says "No books to read. Import a book with its content (Settings)." The **Readable** column in **Settings**, **Books** shows which books have text.
