# Bundled fonts

The PDF export (MIMIR-T-0751) compiles these into `mimir-print`, so a PDF has
the same fonts on every machine, whatever fonts the system has.

| Folder | Font | Version | License |
|---|---|---|---|
| `inter/` | Inter: Regular, Bold, Italic, Bold Italic | 4.1 | SIL OFL 1.1 (`inter/OFL.txt`) |
| `jetbrains-mono/` | JetBrains Mono: Regular, Bold | 2.304 | SIL OFL 1.1 (`jetbrains-mono/OFL.txt`) |

Upstream: https://github.com/rsms/inter and
https://github.com/JetBrains/JetBrainsMono. The files are the unmodified
upstream releases, as Debian packages them (`fonts-inter`,
`fonts-jetbrains-mono`).
